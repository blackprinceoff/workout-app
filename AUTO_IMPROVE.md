## Правила перевірки

Після КОЖНОЇ зміни: `npm run test` + `npm run lint` + `npm run build` — усі зелені.

Зміна балансу XP має тримати `tests/economy.test.ts` у межах (normal 660–800 днів, discipline 320–460).
